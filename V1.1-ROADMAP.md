# v1.1 Roadmap — Reversible Context Compression + Quality Eval

## Goals

- Reduce token omissions via deterministic, reversible compression (RCC).
- Preserve replayability: originals on disk, compressed text in prompt, metadata in packet.
- Add provider-backed answer-quality eval tier to measure "fewer tokens, same answers".
- Keep every v1.0 invariant intact (determinism, cap compliance, gateway boundary, fail-closed editing).

## Exit Gates

- [x] `mimir-compress` crate: pure, deterministic `CodeSkeleton` + `JsonCrush` + unit tests
- [x] `IncludedItem.compression` schema extension (additive, optional, backward-compatible)
- [x] Builder wires compression: threshold check, artifact write, budget re-accounting, promotion of omitted candidates
- [x] `packet_hash` stable across two builds of same input with compression on
- [x] `mimir context expand` CLI: hash-verified, fail-closed, with integration tests
- [x] `ToolResultCard` struct matches schema; capped previews; artifact spill pattern
- [x] `TestCard` summarization: failure-focused, deterministic, capped preview
- [x] Answer-quality eval harness: schema extensions, seed fixture, opt-in CLI subcommand
- [x] `mimir eval answer` reports offline verbatim-vs-compressed input-token savings (CI-safe, no key)
- [x] Cache-stability test: prompt byte-identical across rebuilds with compression
- [x] ADR-009 documenting RCC design rationale
- [x] Docs updated: `docs/context-packets.md`, `CHANGELOG.md`
- [ ] Full gate: `cargo test --workspace --all-targets` + `./scripts/validate-production.sh` + SDK regen/drift/build
- [ ] v1.0 release machinery untouched

## Deferred / Stretch

- [ ] Model-callable `retrieve` tool — bounded, capped at 3 retrievals per run. Documented as planned; not wired.
- [ ] Tree-sitter-based `CodeSkeleton` for richer AST-aware elision.
- [ ] Larger answer-quality fixture set (target: 50+ cases).
- [ ] Live provider dispatch + answer grading for `mimir eval answer` (today it reports token savings only; the grading path is scaffolded in `answer_eval.rs` but not wired to the gateway).

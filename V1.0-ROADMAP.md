# Mimir v1.0 Roadmap

## Current State (post-Phase 7)
- Target tag: `v1.0.0`
- Tests: full `./scripts/validate-production.sh` passing locally
- Phase 7 mostly complete: server transport, TUI live data, session importers, SDK types, local cargo-dist artifacts for all configured targets, staged private Node platform packages, and packet sharing/replay bundles
- Local context eval command and `fixtures/context-recall-v1.yaml` dataset are implemented; current local run reports schema-valid results for 15 cases, cap compliance, and mode 4 beating mode 0 on mean file recall.
- Agent workflow productization is now partially implemented: init seeds guidance/check/recipe files, context packets include safe guidance files, `context suggest` persists provider-free starting packets, `check` runs source-controlled checks, `explore` persists read-only evidence, and code-mode `.mimir/commands/*.md` recipes can be rendered into provider-bound code runs.

## Goal: v1.0.0
Ship when every bullet in `18-DEFINITION-OF-DONE.md` is true.

## Workstreams

### WS1: Missing CLI Commands (High Priority)
- `mimir ask "<question>"` — answer with context, no edits
- `mimir context suggest "<task>"` — build and persist provider-free starting context with guidance, likely files, omissions, and checks — implemented
- `mimir explore "<question>"` — run read-only subagent exploration and persist evidence — implemented
- `mimir check --ci --json` — run source-controlled checks without a provider call — implemented
- `mimir code --recipe <name> --param key=value` — validate and render code-mode `.mimir/commands/*.md` recipes into provider-bound runs — implemented
- `mimir plan "<task>"` — generate PatchPlan
- `mimir code "<task>"` — full edit loop (from phase3-editloop tag)
- `mimir packet share <run_id>` — export portable redacted replay bundles
- `mimir packet replay <run_id|bundle.json>` — verify and emit byte-identical redacted provider requests
- `mimir override request --cap <n> --reason <text>` — cap override flow
- `mimir trace export --redact <run_id>` — trace portability
- `mimir memory distill|forget` — memory management
